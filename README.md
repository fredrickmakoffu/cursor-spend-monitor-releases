# AI Usage downloads

Installers for AI Usage (cursor-spend-monitor) for Fedora and Debian/Ubuntu, with Windows and macOS to follow.

Download the latest build from the [releases page](../../releases) or the [download site](https://fredrickmakoffu.github.io/cursor-spend-monitor-releases/). Verify files against `SHA256SUMS`.

The source is private; this repo only hosts release files and the download page.
